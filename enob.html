Origem da fórmula ENOB = (SINAD − 1.76) / 6.02
1
O que é SINAD?
SINAD = Signal to Noise And Distortion. Mede em dB a razão entre o sinal útil e tudo que atrapalha (ruído térmico + distorção harmônica).
SINAD (dB) = 20 · log₁₀( Vsinal / Vruído+distorção )
2
SINAD teórico de um ADC ideal de N bits
Para um ADC ideal (ruído = apenas erro de quantização), o SINAD máximo possível é:
SINADideal = 6.02 · N + 1.76 (dB)
6.02 = 20 · log₁₀(2) = 6.0206 dB  →  cada bit que se adiciona dobra os níveis e melhora o SINAD em 6 dB.

1.76 = 10 · log₁₀(3/2) = 1.7609 dB  →  vem da estatística do erro de quantização: o erro se distribui uniformemente entre ±½ LSB, e sua potência é LSB²/12. Esse offset é constante, independe de N.
3
Invertendo para obter o ENOB
Para um ADC real, medimos o SINAD na bancada e perguntamos: "quantos bits ideais equivalem a esse SINAD?" — basta isolar N:
SINAD = 6.02 · ENOB + 1.76

ENOB = (SINAD − 1.76) / 6.02
4
Aplicando ao RP2350
O datasheet informa SINAD ≈ 57.2 dB (típico):
ENOB = (57.2 − 1.76) / 6.02 = 55.44 / 6.02 ≈ 9.21 bits
ADC ideal de 12 bits teria SINAD = 6.02×12 + 1.76 = 74.0 dB.
O RP2350 perde 74.0 − 57.2 = 16.8 dB → equivale a 2.8 bits perdidos.
// Analogia para a sala de aula
Imagine uma régua com marcações de milímetro (12 bits = 4096 divisões). Mas sua mão está tremendo (ruído interno do ADC). Na hora de medir, você só consegue confiar nas marcações de ~5mm — as de milímetro ficam dentro da faixa do tremor. Isso é o ENOB: a régua tem 4096 marcas gravadas, mas o tremor deixa apenas ~598 delas confiáveis. O ENOB diz exatamente quantas marcas você realmente pode usar.
